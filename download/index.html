院内のパソコンで使う（ダウンロード）

インターネットにつながらないパソコンでも使えます。環境に合わせて、次の2つのどちらかを選んでください。

おすすめ

方法1　使うパソコンで「インストール」する

そのパソコンが一度でもインターネットにつながるなら、これが最も簡単です。ファイルのやり取りは要りません。

  1. そのパソコンで 分析アプリ を開く
  2. アドレス欄の右端に出る「インストール」ボタン（⊕のようなアイコン）を押す
  3. 「インストール」を選ぶと、スタートメニューとデスクトップにアイコンができます
  4. 以後は、そのアイコンから起動します。インターネットがなくても動きます

※ インストールした状態を USB で別のパソコンに移すことはできません。使うパソコンそれぞれで行ってください。
※ ボタンが出ないときは、ブラウザ右上の「…」→「アプリ」→「このサイトをアプリとしてインストール」。

分離環境向け

方法2　ファイルをダウンロードして USB で持ち込む

使うパソコンがインターネットに一切つながらない場合は、こちらです。

オフライン版 一式をダウンロード（約4MB・ZIP）

  1. インターネットにつながるパソコンで、上のボタンからダウンロードする
  2. ZIP を右クリック →「すべて展開」
  3. 展開したフォルダを USB メモリにコピーし、院内のパソコンに移す
  4. 「1_アプリ」の ImSAFER分析支援_オフライン版.html をダブルクリック

同梱：アプリ（オフライン版・最小版・ビューア）／Excel入力シート／練習用教材／操作ガイド／情報システム担当者向けの説明／ハッシュ値一覧

ファイル単体でほしい場合： 分析アプリ　/ 最小版　/ ビューア

オフライン版について

ウイルス対策ソフトによっては、HTML ファイルの中で Excel ファイルを組み立てる処理などが、 攻撃手口（HTML スマグリング）と形が似ているために検知されることがあります。 オフライン版は、その原因となる処理を取り除いたものです。分析の機能（手順1〜7・QuickSAFER・印刷/PDF）はすべて使えます。

「最小版」は、オフライン版でもウイルス対策ソフトに止められた場合の控えです。まずはオフライン版をお試しください。

ダウンロードが止められた場合
同梱（または このページ）の 「セキュリティ検知について_情報システム担当者の皆さまへ」を、貴院の情報システム担当者にお渡しください。 検知された理由、外部通信を行わないことの確認結果、ファイルのハッシュ値を記載しています。 ソースコードは GitHub で全文を公開しています。

共通の注意

  • 入力した内容が外部へ送られることはありません。保存先はお使いの端末の中だけです。
  • 患者氏名・患者ID・病室番号は入力しない運用にしてください（登場人物は「患者A」「看護師A」と表記）。
  • パスワード付きファイルは、Web 版とオフライン版で保存形式が異なります。両方で使う場合はパスワードなしで保存してください。
  • 共用のパソコンで使ったときは、分析が終わったらファイルを保存し、ブラウザの履歴・サイトデータを消してください。
