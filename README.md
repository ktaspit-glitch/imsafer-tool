# ImSAFER 分析支援

医療事故・インシデントの事例分析（ImSAFER の手順1〜7）を、紙の付箋と模造紙のかわりに画面で行うための道具です。
無料・登録不要。インターネットに接続せず動き、入力した内容は利用者の端末内だけに保存されます。

- **紹介ページ**： `index.html`
- **分析アプリ**： `app/`（スマホ対応・ホーム画面に追加でオフライン動作）
- **ビューア**： `viewer/`（閲覧専用。練習事例を内蔵）

## 使い方
1. 公開ページを開く
2. 「分析アプリ」→「練習事例をひらく」で、中身の入った事例をすぐ試せます
3. スマホはブラウザのメニューから「ホーム画面に追加」
